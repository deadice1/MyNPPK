# Сетевой слой и API эндпоинты

Приложение взаимодействует с двумя разными серверами. Koin разделяет их через `named` квалификаторы.

## 1. Сервер Групп и Авторизации (GroupRetrofit)
**Base URL:** `http://80.89.199.85:8081/`

| Метод | Эндпоинт | Описание |
| --- | --- | --- |
| POST | `/api/users/authenticate` | Вход в систему. Возвращает роль и ID пользователя. |
| GET | `/api/groups` | Получение списка всех доступных групп. |
| GET | `/api/students` | Получение списка студентов для поиска профиля по `user_id`. |
| GET | `/api/groups/{id}` | Детальная информация о группе (название по ID). |
| PUT | `/api/users/{id}` | Обновление данных (смена пароля). |

## 2. Сервер Расписания (ScheduleRetrofit)
**Base URL:** `http://147.124.204.18:8000/`

| Метод | Эндпоинт | Описание |
| --- | --- | --- |
| GET | `/api/schedule/{group_name}` | Загрузка пар для конкретной группы. |
| GET | `/api/subjects` | Список предметов (для режима преподавателя). |

## Формат ответа
Почти все ответы обернуты в стандартный объект:
```json
{
  "status": "success",
  "data": { ... }
}
```
**Важно**: Приложение проверяет именно строку `"success"`. Если поле `status` содержит `"error"`, логика репозитория возвращает ошибку или пустой список.
